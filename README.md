## 关于

我的个人技术博客，记录在 Web3、AI Agent、安卓逆向与独立开发上的折腾、踩坑与思考。
文章用 Notion 管理，自动同步渲染为静态站点并部署在 Vercel。

## 技术栈

- **Next.js / React** — 前端与静态生成（ISR）
- **Notion** — 内容管理（CMS）
- **Vercel** — 构建、部署与 CDN

## 本地开发

```bash
yarn install
yarn dev
```
